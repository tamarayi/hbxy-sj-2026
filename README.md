# “迎春花”实践队 · 三下乡路线图

一个可以自己维护的实践路线网页：地图上按顺序标出走过的地方，点开标记就能看到文字、图片和视频。

---

## 一、怎么打开看

**双击 `index.html`** 即可。不需要装任何软件，不需要联网（除了地图底图需要联网加载）。

## 二·五、标记点聚合（地图缩放行为）

点位多了以后，挨得近的点会挤在一起。现在做了自动聚合：

- **缩小地图时**：相距近的地点自动合并成一个绿色大圆点，圆点里的数字是**合并了几个点**
- **点一下大圆点**：地图自动放大展开
- **放大到 13 级以上**：自动散成一个个带序号的独立标记
- **从底部时间轴点任意一个地点**：地图会自动定位并展开，保证那个标记能被看到

想调整聚合的灵敏度，打开 `js/app.js` 找这两行：

```js
var CLUSTER_BREAK_ZOOM = 13;   // 放大到几级就散开（数字越大越容易聚合）
maxClusterRadius: 65,          // 多少像素内的点算“挨得近”（数字越大越容易聚合）
```

## 三、怎么增加一个地点

数据文件的结构是「两支队伍，各一条路线」：

```js
window.TEAMS = [
  { id:"yingchunhua", name:"“迎春花”实践队", color:"#1f7a4d", places:[ 地点1, 地点2, ... ] },
  { id:"huanweiweshi", name:"“环保卫士”实践队", color:"#1c5d99", places:[ 地点1, 地点2, ... ] }
];
```

**每个队的 `places` 数组就是那个队的地图路线，数组顺序 = 路线顺序。**

1. 用记事本或 VS Code 打开 `data/places.js`
2. 找到文件最下方的 **【新增一个地点】** 注释块
3. 把那一整块 `{ ... },` 复制出来，粘贴到**你想加的队伍的** `places: [ ... ]` 里
4. 把开头的 `//` 注释符删掉，然后改成你的内容：

```js
  {
    name: "新地点名称",              // 地图标记和列表上显示的名字
    short: "短标签",                 // 可选，时间轴上的简短说明
    date: "2026年7月9日",            // 日期
    coords: [25.8580, 114.5680],     // ★ 经纬度，纬度在前
    summary: "一句话简介",
    intro: "这里写我们在这个地方做了什么。\n\n可以写很多字，用两个反斜杠n分段。",
    media: [
      { type: "image", src: "images/新地点-1.jpg", caption: "图片说明" }
    ]
  },
```

5. 保存，刷新网页 ✅

**⚠️ 最容易出错的地方：** 每个 `{ }` 后面要有**英文逗号** `,`，最后一块后面不要逗号。写错了页面顶上会出现橙色提示条告诉你哪里有问题，不会白屏。

## 四、怎么加图片

1. 把照片复制到 `images` 文件夹，建议改个看得懂的名字，比如 `河唇村-支教-1.jpg`
2. 在对应地点的 `media` 里加一行：

```js
{ type: "image", src: "images/河唇村-支教-1.jpg", caption: "趣味课堂现场" }
```

**建议：**
- 图片文件名**不要用中文标点和空格**，用短横线 `-` 连接最保险
- 上传前把图片压缩到 500KB 以内（否则网页打开很慢），推荐网站：`tinypng.com`
- `src` 留空 `""` 时，页面会显示一个灰色占位块提醒你这里该放图

## 五、怎么加视频

### 方式一：传到 B 站再嵌入（推荐，适合大视频）

1. 把视频上传到 B 站（可以设置成"仅自己可见"以外的任意可见范围）
2. 打开视频页面，复制嵌入代码里的链接，格式是：
   `https://player.bilibili.com/player.html?bvid=BV1xx411c7mD`
3. 写进 `media`：

```js
{ type: "bilibili", src: "https://player.bilibili.com/player.html?bvid=BV1xx411c7mD", caption: "实践纪实视频" }
```

### 方式二：本地 mp4 文件（只适合十几秒的小片段）

```js
{ type: "video", src: "videos/河唇村.mp4", caption: "视频说明" }
```

**⚠️ 单个文件不要超过 100MB**，否则传不上 GitHub。视频建议格式 `mp4 (H.264)`。

### 方式三：腾讯视频

```js
{ type: "tencent", src: "https://v.qq.com/txp/iframe/player.html?vid=视频ID", caption: "说明" }
```

## 六、怎么查一个地点的经纬度

**网页里的坐标已经换算成高德坐标系（GCJ-02），和底图是对齐的，不用再转换。** 乡镇一级（营前镇、油石乡、东山镇）来自 OpenStreetMap 实测数据，可靠；村一级是按政府公开的村情简介推算的，有几米到几百米误差。

1. 打开高德坐标拾取器：<https://lbs.amap.com/tools/picker>
2. 在搜索框输入地点名（如"上犹县油石乡河唇村"），或直接在地图上点击具体位置
3. 右上角会显示坐标，格式是 `114.5680,25.8580`（**经度在前**）
4. 填进 `places.js` 时**要反过来写**：`coords: [纬度, 经度]` → `coords: [25.8580, 114.5680]`

> 为什么用高德的坐标？因为地图底图用的就是高德瓦片，两者坐标系一致，标记点才会压在正确位置上。

## 七、怎么发布到网上（GitHub Pages）

发布后你会得到一个类似 `https://你的用户名.github.io/sanxiaxiang/` 的链接，发到微信群谁都能打开。

### 第 1 步：注册 GitHub 账号
打开 <https://github.com/signup>，用邮箱注册（国内访问偶尔慢，耐心等或换个网络）。

### 第 2 步：新建仓库
1. 登录后点右上角 `+` → `New repository`
2. `Repository name` 填 `sanxiaxiang`（英文小写，不要有空格）
3. 选 **Public**（免费账号必须公开才能用 Pages）
4. 勾选 `Add a README file`
5. 点 `Create repository`

### 第 3 步：上传文件
1. 进入刚建好的仓库，点 `Add file` → `Upload files`
2. 把这个文件夹里的**所有内容**（`index.html`、`css`、`js`、`data`、`images`、`videos`）拖进去
3. 下方填一句说明，点 `Commit changes`

### 第 4 步：开启 Pages
1. 仓库页面点 `Settings`（设置）
2. 左侧菜单找到 `Pages`
3. `Source` 选 `Deploy from a branch`
4. `Branch` 选 `main`，文件夹选 `/ (root)`，点 `Save`
5. 等 1–2 分钟，刷新页面，顶部会出现绿色提示和你的网址

### 第 5 步：以后怎么更新
改完 `places.js` 后，回到仓库，点进 `data/places.js` → 右上角铅笔图标 → 粘贴新内容 → `Commit changes`，等一分钟网页就更新了。

## 八、常见问题

**Q：打开后地图是灰的、没有地名？**
底图需要联网。检查网络；如果国内某些网络访问不了高德瓦片，换个网络再试。

**Q：标记点位置偏了？**
坐标不准。用第六节的方法重新取坐标。

**Q：改了 `places.js` 网页没变化？**
浏览器缓存。按 `Ctrl + F5` 强制刷新。

**Q：页面顶上出现橙色警告条？**
说明数据有格式错误，条上会写清楚是第几个地点、哪里错了，照着改即可。

**Q：想在手机上直接看？**
把整个文件夹拷到手机，用手机浏览器打开 `index.html` 也能用（地图需要联网）。
